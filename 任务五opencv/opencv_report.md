OpenCV赛道检测实验说明
 
1.HSV颜色阈值选择
本任务采用HSV色彩空间提取黄色赛道,BGR色彩空间容易受光照亮度干扰，HSV将色相、饱和度、亮度分离，颜色识别更加稳定
选取黄色阈值： lower_yellow = [15, 80, 80] ， upper_yellow = [35, 255, 255] 
H（色相）15‑35 覆盖黄色区间
​S（饱和度）80以上过滤低饱和背景
​V（亮度）80以上过滤过暗区域
通过 cv2.inRange() 生成二值掩码，将符合黄色阈值的像素置为白色255，背景置为黑色0，完成赛道区域初步提取
 
2.形态学操作的作用
得到二值掩码后，使用开运算与闭运算做形态学处理：
  1. 开运算 消除图像外部孤立的小白噪点
  2. 闭运算 填充赛道内部细小黑色孔洞，让赛道区域更加完整连续
  经过开闭运算处理后得到干净的二值图像，降低后续轮廓检测和中心线计算的误差
 
3.中心线提取思路
我采用了列扫描法求取赛道中心线：
1. 遍历二值图像的每一行，找到该行白色赛道区域的最左边界  idx[0]  和最右边界  idx[-1] 
2. 计算该行赛道中心点： x_mid = (x_left + x_right) // 2 ，得到当前行的中心线坐标。
3. 收集所有有效中心点，在原图副本上绘制红色圆点，拼接形成完整赛道中心线
4. 同时使用 findContours 检测二值图的赛道外轮廓，在copy图上绘制绿色轮廓边界




整体流程
读取原图  BGR转HSV  inRange生成二值掩码   开运算去噪   闭运算补洞   轮廓检测绘制绿色赛道轮廓   列扫描计算每行赛道中心   绘制红色中心线   输出可视化结果
